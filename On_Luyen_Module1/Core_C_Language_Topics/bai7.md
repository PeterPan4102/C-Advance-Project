7. **Chương trình sau có hoạt động không? Nếu không, vấn đề là gì?**
    ```c
    int month = 5;
    if (month = 1) {
    printf("January");
    } else {
    printf("Not January");
    }"
    ```
    Chương trình trên sẽ không thể hoạt động được.

    Lý do là vì khi thực hiện cú pháp `if()` so sánh bằng thì cú pháp đúng phải là `if(a == b)`, dấu `=` là phép gán và dấu `==` mới là phép so sánh.
